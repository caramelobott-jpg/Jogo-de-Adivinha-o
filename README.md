🎯 Jogo de Adivinhação

Um jogo simples em Python onde o computador sorteia um número secreto entre 1 e 100, e o jogador precisa tentar adivinhar, recebendo dicas de "maior" ou "menor" a cada tentativa.

Como funciona
O programa sorteia um número aleatório entre 1 e 100
O jogador digita um palpite
O programa diz se o número secreto é maior ou menor que o palpite
O jogador continua tentando até acertar
Quando acerta, o jogo mostra "Vencedor!" e termina
Tecnologias usadas
Python 3
Módulo random (para sortear o número)
Conceitos praticados
Laços de repetição (while True)
Estruturas condicionais (if / elif / else)
Entrada de dados do usuário (input())
Conversão de tipos (int())
Controle de fluxo (break)
Como executar
bash
python cod2.py

Digite um número quando solicitado e siga as dicas até acertar!

Exemplo de execução
Digite seu numero: 50
Tente um numero menor
Digite seu numero: 25
Tente um numero maior
Digite seu numero: 37
Vencedor!
